# Workflow — First-run intelligence setup

`install → privacy posture → device scan → workflow interview → provider choices → repo choices → context migration choices → recommendation plan → approval → model/provider provisioning → repo/context import → role/workflow/skill assignment → qualification → restart → ready receipt`

## Required receipts

- application/source version;
- setup profile version and provenance summary;
- device snapshot used for recommendations;
- each network action and user consent;
- model pack exact identities and qualification result;
- provider/account/model route identities without secrets;
- imported repositories and permissions;
- migrated context source + accepted/rejected counts;
- enabled workflows/skills and why;
- final readiness checks;
- restart recovery result.

A skipped optional step is not a failure. A required readiness dependency that is unavailable yields DEGRADED/BLOCKED, not READY.
