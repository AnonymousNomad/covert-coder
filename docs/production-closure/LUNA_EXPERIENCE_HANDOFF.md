## Immediate instruction

Do not redesign or build the full public site blindly.

First establish an authored design system and website experience plan.

At the next relevant design checkpoint provide:

- current site/product surfaces;
- Figma/design-system state;
- typography/color/material system;
- anti-pattern audit;
- 3-7 mechanism references;
- two distinct homepage composition directions;
- one recommended dominant interactive mechanism;
- implementation stack;
- reduced-motion design;
- performance fallback;
- mobile strategy;
- browser/visual QA plan.

Use Figma for system design when available.

Use Vercel/React/Next.js plus Three.js/R3F/GSAP only where justified.

Use real Covert product/evidence data.

Do not use generic AI-generated SaaS defaults.

Do not copy another site's identity.

The objective is for a technically literate visitor to conclude:

"This was designed and engineered deliberately."

Production closure remains the primary release gate.
