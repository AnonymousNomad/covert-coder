# Covert Visual Anti-Pattern Register

This is a review checklist, not an absolute blacklist.

## High-risk default combinations

Reject by default when multiple are present without deliberate reasoning:

- purple/blue radial glow behind centered hero;
- gradient-filled H1;
- one-sentence vague AI promise;
- two pill CTAs;
- floating dashboard in perspective;
- three identical feature cards;
- bento grid immediately below hero;
- every container rounded 16-24px;
- translucent black glass cards;
- Lucide icon in a colored rounded square;
- testimonials in identical cards;
- random star/particle background;
- universal scroll fade-up;
- glowing borders;
- fake terminal window;
- stock AI robot/brain/neural network;
- "trusted by" logos with no relationship;
- invented performance numbers;
- vague superlative copy.

## Acceptable only when justified

- gradient;
- glass;
- rounded corners;
- bento layouts;
- dark mode;
- particles;
- glow;
- 3D;
- parallax;
- terminal motifs.

These are materials, not identity.

## Covert alternatives

Instead of generic particle background:
- particles represent model/workflow/context flow.

Instead of fake terminal:
- use a real recorded or interactive Covert terminal.

Instead of random dashboard card:
- expose a real Covert subsystem.

Instead of generic feature grid:
- walk through a real operator workflow.

Instead of "AI-powered":
- state what Covert actually controls or executes.

Instead of abstract benchmark number:
- expose task, raw output, grader, runtime, hash, revision.

Instead of cosmetic gauges:
- bind to real telemetry.
