# REFERENCE USAGE / VISUAL-DIFF METHOD

For every theme, keep the owner reference visible beside the running Design Lab.

## Before writing CSS
Measure and write down:
- major horizontal bands;
- column proportions;
- dominant visual anchor;
- location of navigation;
- location of Resident/chat;
- location of editor/work;
- location of terminal/output;
- location of models;
- location of telemetry;
- location of activity/liveness visual.

Use the annotated references in `../02_ANNOTATED_REFERENCES/`.

## Required comparison loop
1. Open owner reference.
2. Open Design Lab at matching aspect ratio.
3. Capture screenshot.
4. Put reference and screenshot side-by-side.
5. Compare **composition before color**.
6. Correct major geometry.
7. Compare typography/density.
8. Correct hierarchy.
9. Compare identity/art/activity treatment.
10. Only then polish color, border and glow.

## Owner review submission
For each theme submit exactly:
- owner reference;
- new actual-browser capture;
- side-by-side composite;
- 5–10 intentional differences with reasons;
- unresolved mismatches;
- no production acceptance claim.

Do not submit three themes together. One theme, one review gate.
