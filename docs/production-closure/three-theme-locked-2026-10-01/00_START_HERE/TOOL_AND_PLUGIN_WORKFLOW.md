# TOOL / PLUGIN WORKFLOW FOR SOL 6.1

This is the required tool order. Do not let a paid Figma limitation block the job.

## Required

### 1. Remote Desktop Commander — primary local execution
Use it to:
- inspect the current and historical Covert worktrees;
- search local branches/reflogs/stashes/backups for Luna's prior successful UI;
- run the isolated Design Lab;
- inspect files and logs;
- launch real browser/Edge validation;
- capture evidence and verify that production code remains untouched until approval.

### 2. GitHub — source archaeology and evidence
Use it to:
- search all remote branches/commits for prior UI/theme work;
- compare exact SHAs;
- preserve rejected/accepted checkpoints;
- attach review evidence to the existing release-control process.

Current remote code search did **not** find exact phrases from the old colorful screenshot such as `PRIVATE MINDS`, `ZERO COMPROMISE`, `SILENT TOOLS`, or `DIFFERENT MINDSET`. Therefore do not assume the prior Luna implementation is on the current remote branch. Search local refs/worktrees/history before recreating it.

### 3. Context7 — implementation truth
Use it when implementing framework/library behavior such as:
- Monaco/editor APIs;
- state management;
- CSS/layout APIs;
- accessibility/reduced-motion APIs;
- any third-party UI library actually present in Covert.

Do not guess API behavior from memory when current docs are available.

### 4. Exa or normal web research — bounded design research
Research only to support this package:
- IDE docking/resizing;
- developer workstation telemetry;
- accessibility;
- performance/motion;
- observability density.
Do not let external products replace the owner references.

### 5. Real browser validation — mandatory
Use the actual browser/Edge route used by Covert. Capture:
- target laptop viewport;
- narrower viewport;
- zoom/scaling;
- reduced motion;
- all panel resize extremes.
Screenshots from a generated image are not acceptance evidence.

## Optional

### Figma
Current connected Figma plan is Starter + View seat and cannot support agent canvas authoring. Treat Figma as optional/read-only/reference. Do not spend money and do not block work on it.

### Image generation
Use only when a new original Covert-safe asset is required (for example a corporate activity figure or Original Resident artwork). Generate original artwork; do not imitate recognizable franchise characters.

### Canva
Optional for static presentation boards only. Do not use it as the product implementation source of truth.

## Prohibited workflow
- "I looked at the reference and improvised a dashboard."
- Figma quota/seat as a blocker.
- One generic component composition recolored three times.
- Production mutations before the Design Lab view is owner-approved.
