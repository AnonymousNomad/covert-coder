# THEME 01 — CORPORATE EMERALD / DEFAULT

Reference: `../01_REFERENCES/01_CORPORATE_EMERALD_OWNER_REFERENCE.png`

## Goal
A professional engineering workstation that can be used for eight-hour sessions. Compact branding, dense useful information, graphite/gunmetal construction, emerald identity, and subtle purposeful illumination.

## Important interpretation of the reference
The top half of the supplied image is a brand/mood board. The **lower workstation image is the structural base**. Do not turn the top mood board into giant in-app branding.

## Baseline 1600x900 composition

### Top bar — 54 px
Left to right:
1. 28–32 px Covert sigil
2. `COVERT CODER` compact wordmark
3. global command/search input occupying 32–38% width
4. project selector
5. provider/local/offline state
6. **activity figure/dial** at the far right, 44–52 px collapsed; clicking opens its 150 px diagnostic popover/card.

### Activity rail — 76 px
Icon-first vertical rail:
Explorer, Search, Source Control, Run/Debug, Resident, Models, Skills, Memory, Verification, System Health, Settings.

Default: icon + tooltip. Expand to labels only when user requests wider density.

### Project/context pane — 248 px
Top: PROJECT.
Then tree.
Bottom 25–30%: Selected Context / Project Brain preview.
This pane can collapse completely.

### Main center
Editor is dominant.
Tabs 34–38 px.
Breadcrumb/context strip 24–28 px.
Editor minimum 520 px width.

Bottom execution pane defaults to 236 px:
`Terminal | Output | Problems | Verification | Tasks | Evidence`
Resizable vertically, maximizable, collapsible.

### Right intelligence pane — 344 px
Top-to-bottom:
1. **Activity figure / liveness instrument** — 150 px
2. **Resident chat** — 350 px preferred minimum 280
3. Model/runtime access — 120 px
4. Telemetry cluster — remaining space, minimum 160 px

Do not replace Resident with a static status card. It needs real conversation history, quick actions and composer.

## Resident chat anatomy
Header:
- Resident avatar/sigil 24–28 px
- `Resident`
- current role/model subline
- context/tool/status tabs or compact chips

Body:
- scrollable message history
- evidence/source chips when applicable

Quick actions:
- Plan a feature
- Implement a task
- Review changes
- Check system health
- Run verification
- Open model manager

Composer:
- multiline input
- attach/context button
- mode/model selector
- send/stop button
- activity state next to send button

## Corporate activity figure
The owner's top-right hooded figure concept is the signature liveness instrument. Use original Covert-safe artwork, not franchise mimicry.

Collapsed state: compact sigil/hooded head with lit core/eyes.
Expanded card: 150–180 px tall with state label, last progress timestamp and current operation.

No continuous rotation in IDLE.
Motion stops in STALE/FAILED.
See shared activity state machine.

## Telemetry placement
Bottom-right only.
Order:
1. RAM
2. Commit pressure
3. GPU/VRAM
4. CPU
5. Storage
6. runtime/model/provider line

Use mixed instrument types, not identical donuts:
- CPU arc
- RAM segmented ring
- Commit vertical/horizontal pressure bar
- GPU/VRAM dual instrument
- Disk bar
- runtime status row

## Surface treatment
- primary base `#080F14`
- elevated `#1A1F26`
- secondary `#2A3038`
- main focus `#00E0A4`
- cyan only for links/navigation/info
- violet for model/reasoning
- amber only warning/degraded/waiting
- red/rose only error/critical intervention

Borders: 1 px default, 2 px active.
Glow: use on focused/active edges only, not whole cards.
Corner radius: 4–8 px, not bubbly SaaS cards.

## Lock criteria
Corporate does not proceed until owner approves:
- major geometry;
- Resident chat;
- bottom-right telemetry;
- activity figure;
- compact branding;
- professional density.
