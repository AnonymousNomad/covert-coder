# VISUAL REVIEW CHECKLIST

Score each item PASS / FAIL / OWNER DECISION.

## Composition
- [ ] Major bands/columns match reference intent.
- [ ] Editor/work surface is dominant.
- [ ] Resident is in the intended place.
- [ ] Terminal/output is reachable without navigation churn.
- [ ] Telemetry is supportive, not dominant.
- [ ] Brand art does not steal coding space.

## Identity
- [ ] Theme is immediately distinguishable from the other two.
- [ ] Theme-specific activity language is visible.
- [ ] Buttons/controls use purposeful illumination.
- [ ] Color meanings remain semantic.
- [ ] No generic SaaS-card appearance.

## Usability
- [ ] Main panes resize.
- [ ] Panes collapse/restore.
- [ ] Layout persists.
- [ ] Keyboard focus visible.
- [ ] Narrow viewport remains usable.
- [ ] Zoom/scaling does not overlap/clamp critical controls.

## Truth
- [ ] Design Lab fixture labeling visible.
- [ ] Production UNKNOWN/UNAVAILABLE not converted to 0.
- [ ] Activity motion stops on stale/failure.
- [ ] No fake sparkline in production.
