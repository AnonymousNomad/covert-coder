# Cipher and Buddy contract

## One Resident, separate presentation

ResidentID/binding stays stable across worker changes. Standard: compact factual status plus invoked full window. Buddy: optional presence of same Resident, not another executor/memory/authority.

Separate Resident, personality, voice route, chassis, animation pack, idle preferences. Any approved persona/voice works with any chassis. Developers Special is original terse/demanding/evidence-oriented delivery; no changed truth/grants or random insults.

Use Context Control and existing scoped journal/task/evidence/preferences for continuity. Cosmetic laptop is separate from structured records. Discover terminal existence does not grant scrollback access. Credentials never become ordinary context.

Delegate specialists through existing Orchestrator/Authority/Admission/qualified routes. Show actual performer/egress/evidence on inspection. Do not claim a recommended route executed.

## Capture and routes

Off/PTT/Active Conversation/Continuous with explicit opt-in; start with qualified PTT if available. Actual mic/processing/speaking and route/data destination visible. Device permission does not grant egress/retention.

Independent Stop Listening, Stop Speaking, Mute Output, Buddy Off. Mute stops output, not capture. Hide suspends body, never capture indicator. Buddy Off stops optional capture/output/proactivity/body and returns Standard; task stop separate.

Lock/sleep/restart stop optional capture/output. Restore preference, not active mic. No model/voice selfapproval replacing independent operator Authority.

Vision is purposeful selected attachment through qualified route. Structured state preferred; no continuous screenshots/OCR. Browser speech not assumed local; no silent cloud fallback.
