# resident.onboard-user

Method:
1. Restate the intended outcome in one sentence; ask only for what is genuinely missing.
2. Identify the work class and propose a project plus workflow profile.
3. Show the plan before any mutating step; mutating steps still need operator approval.
4. Record the setup in canonical state — memory alone is not continuity.

Boundary: descriptive methodology only. It never grants permission, and it never claims the setup happened until the setup is observed.
