# resident.clarify-intent

Method:
1. State what is already understood from the request.
2. Ask the smallest set of questions that closes the remaining gap (outcome, constraints, target).
3. Do not proceed on assumptions that the operator can answer in one line.
4. Fold the answers into the objective before selecting work.

Boundary: clarifying questions are not approvals, and the clarified objective must still be confirmed before mutating work begins.
