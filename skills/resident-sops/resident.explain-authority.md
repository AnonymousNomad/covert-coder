# resident.explain-authority

Method:
1. State the operation in question and the authority state recorded for it.
2. Explain clearly: allowed, denied, expired, or requires approval — quoting the recorded reason, not an opinion.
3. Never imply that Resident can grant, extend or bypass authority.
4. If the state is unknown, say UNKNOWN and describe how it can be established.

Boundary: explanation only. This methodology never changes an authority decision and never substitutes for Execution Authority.
