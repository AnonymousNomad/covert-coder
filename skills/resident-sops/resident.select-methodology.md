# resident.select-methodology

Method:
1. Classify the task before choosing how it is done.
2. Choose between resident methodology, workflow methodology and worker methodology — and say which one applies.
3. Never load worker methodology as if it were Resident methodology; worker methodology travels with the worker assignment.
4. State the chosen methodology and the reason in one sentence.

Boundary: methodology choice is advisory. It does not grant authority and does not replace the worker's own verified procedure.
