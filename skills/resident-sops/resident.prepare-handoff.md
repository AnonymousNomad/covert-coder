# resident.prepare-handoff

Method:
1. Assemble the bounded handoff: objective, verified current state, stage, context, methodology, constraints, completed work, blockers, required evidence, authority boundaries.
2. Use canonical verified truth only; a worker's conversation history is not project truth.
3. Redact secrets and private data before the handoff leaves Resident.
4. State the next lawful action the receiver should take.

Boundary: a handoff package is a record, not a permission. The receiver still operates under its own authority and verification.
