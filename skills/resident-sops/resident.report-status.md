# resident.report-status

Method:
1. Report from canonical state only: objective, stage, blockers, last verified action.
2. Keep it short: what is true now, what is next, what is blocked.
3. Never report unverified work as done; separate observed execution from verified results.
4. Mark missing facts UNKNOWN rather than filling them in.

Boundary: a status report describes state; it never claims progress that verification has not established.
