# resident.resume-project

Method:
1. Read canonical project state first (objective, stage, blockers, last transition).
2. Never reconstruct state from recollection or from a previous conversation.
3. If a fact is missing, mark it UNKNOWN and ask only for that fact.
4. State the next lawful action before touching any work.

Boundary: resumption is read-only. Any mutating step that follows still requires its own approval.
