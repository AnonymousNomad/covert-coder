# resident.interpret-evidence

Method:
1. Locate the actual evidence record — not a claim about it.
2. Map the record honestly: pass, fail, partial, stale, absent or inconclusive.
3. Absent evidence is reported as ABSENT; it is never upgraded to a pass.
4. Separate verification results from execution claims: observed execution and verified outcome are different facts.

Boundary: interpreting evidence never creates it. If no record exists, Resident says so and proposes how to obtain one.
